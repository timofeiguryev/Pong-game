# Pong Game

Simple game, written in Python, where a player uses a paddle to hit the ball against the wall.

## About Pong

Pong is one of the earliest arcade games and a pioneering title in the video game industry. Released by Atari in 1972, it was a commercial success and helped establish video games as a viable enter[...]

## Overview

This project is a Python implementation of the classic Pong game, recreating the simple yet engaging gameplay that made the original a landmark in gaming history.

## Instructions

### Required

- **Python 3.8 or higher**
- **Pygame** (Python library for game development)

### Installation

1. Install Python from [python.org](https://www.python.org) if not already installed
2. Install Pygame using pip:
   ```bash
   pip install pygame
   ```
