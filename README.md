# Pong Game

Simple game, written in Python, where a player uses a paddle to hit the ball against the wall.

## About Pong

Pong is one of the earliest arcade games and a pioneering title in the video game industry. Released by Atari in 1972, it was a commercial success and helped establish video games as a viable entertainment medium.

## Overview

This project is a Python implementation of the classic Pong game, recreating the simple yet engaging gameplay that made the original a landmark in gaming history.

## Instructions

### Required

- **Python 3.8 or higher**
- **Tkinter** (usually included with Python)

### Installation

1. Install Python from [python.org](https://www.python.org) if not already installed
2. Tkinter comes bundled with Python, so no additional installation is needed

### Running the Game

To start the game, navigate to the repository directory and run:
```bash
python paddleball.py
```

### Controls

- **Left Arrow** – Move paddle left
- **Right Arrow** – Move paddle right
- **Space** – Pause/Resume game

### Note

This game has been tested and verified to work on **Windows 10**. Compatibility with other operating systems (macOS, Linux, etc.) has not been tested.
